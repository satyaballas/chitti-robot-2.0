# Photos

Drop pictures into these folders. Short lowercase names with dashes work best on GitHub, e.g. `03-head-led-board.jpg`. A number at the front keeps them in order.

| Folder | What goes in it |
|---|---|
| `teardown/` | the robot being opened: screws, body halves, head LED board (IR receiver at CN3), main board, motors, speaker |
| `parts/` | the Pi, round TFT, IR receiver/transmitter, headset/mic, power bank, jumper wires |
| `build/` | wiring in progress, the screen behind the visor, the IR LED placement |
| `finished/` | Chitti assembled and running (one good front shot becomes the README's main photo) |

Before uploading, resize photos to about 1600 px on the long side so the repo stays small. Phone photos are 3–8 MB each. Also check that nothing private is in the background: screens, letters, faces.
